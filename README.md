# Категории и Товары

## Описание

Проект реализует две модели: `Product` и `Category`   
С помощью данных классов возможно:

- Создавать продукты с описанием, ценой и количеством.
- Группировать продукты по категориям.
- Вести подсчёт общего количества категорий и продуктов.

E-commerce — это электронная коммерция, или торговля через интернет.

Описание:

На данный момент код просто выводит информацию о товарах: название, количество, цену и описание.

Использование:

Для запуска необходимо открыть файл main.py, в котором используются классы Product и Category из файла classes в папке src.

Тестирование:

Покрытие тестами составляет 100%.
